## Clarification after the project context was written

The user confirmed the feature direction: maps with pins at precise physical locations, where each pin lists the relevant processes. A room can contain multiple pins. Selecting a process leads to voice guidance.

The mockups use German labels, the working name “Hauswissen,” and example content. Furniture positions, process wording, durations, and the visual design are illustrative. Voice and saving are simulated; this is an interaction reference for implementation.

The original project context still describes mapping as a stretch goal. The feature direction above was subsequently clarified; inclusion in the buildathon demo remains a scope decision.
